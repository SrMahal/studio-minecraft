Mods do cliente

Apenas o necessário.
Vamos instalar?

O Simple Voice Chat adiciona voz por proximidade. Sem ele você pode jogar, mas não ouvir nem falar pelo mod.

FABRIC · JAVA 26.2

Simple Voice Chat

voicechat-fabric-2.6.21+26.2.jar

Baixar no Modrinth ↗

01 · Perfil do jogo

Comece pelo
perfil Fabric.

No seu launcher, selecione um perfil Fabric compatível com o Minecraft Java 26.2.

ANTES DE CONTINUAR

Confira a versão.

O jogo, o perfil Fabric e o arquivo do mod precisam ser compatíveis entre si.

Depois de conferir o perfil, feche o jogo para adicionar o mod.

02 · Windows

Abra a
pasta mods.

Pressione Win + R no Windows, cole o caminho abaixo e confirme com Enter.

CAMINHO NO WINDOWS
%appdata%\.minecraft\mods

Se o launcher usa uma pasta própria para o perfil, abra a pasta mods desse perfil. Crie a pasta se ela ainda não existir.

03 · Arquivo do mod

Coloque o arquivo.
Reabra o jogo.

Mova o arquivo .jar baixado para a pasta mods. Depois, inicie o Minecraft pelo perfil Fabric.

ARQUIVO ESPERADO

voicechat-fabric-2.6.21+26.2.jar

Mantenha o arquivo no formato .jar, sem descompactar.

04 · Configuração de áudio

Teste sua voz.
Encontre o grupo.

Entre no Servidor Mahal e pressione V para abrir as configurações do Simple Voice Chat.

VAbrir o mod de voz

Escolha seu microfone.

Confira a entrada e a saída de áudio, ajuste o volume e teste a comunicação perto de outro jogador.
